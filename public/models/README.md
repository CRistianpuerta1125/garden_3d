# Modelos 3D (.glb) para Garden 3D

Coloca aquí tus archivos de modelos 3D en formato `.glb` o `.gltf`.

### Sitios recomendados para conseguir modelos 3D gratuitos:
- **Poly Pizza**: https://poly.pizza (Excelente para vegetación low-poly)
- **Kenney.nl**: https://kenney.nl/assets/nature-kit (Kits de naturaleza 3D libres de derechos)
- **Sketchfab**: https://sketchfab.com (Filtra por descarga libre + .glb)
- **Quaternius**: https://quaternius.com (Packs de naturaleza y plantas 3D)

### Modelos sugeridos para colocar en esta carpeta:
- `flower_1.glb` / `flower_2.glb` (Flores)
- `tree.glb` (Árboles)
- `bush.glb` (Arbustos)
- `grass.glb` (Mechones de pasto)
- `rock.glb` (Rocas / Piedras)
